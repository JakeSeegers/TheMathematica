The Game

game.html · any level

Move & camera

  • WASD/↑←↓→Move (relative to the camera)
  • ShiftholdRun
  • Q/EholdRotate the camera (up to 60° each way)
  • Z/Xor=/−Zoom in / out
  • WheelZoom

Talk & choose

  • Space/Enter/FTalk, read, knock, look · next page
  • Click the dialogueNext page
  • ↑/↓orW/SChoose an answer (or hover and click it)
  • Esc/BackspaceShow the whole page at once

World & time

  • TNext time of day Dawn → Midday → Golden Hour → Dusk → Night
  • RNext weather clear → rain → snow
  • MMusic on / off

The clock runs by itself: one game hour ≈ 90 seconds.

Screens

  • N/TabWorld map (N, Tab, Esc or Backspace closes it)
  • PPhoto mode (P, Esc or Backspace returns)
  • HControls legend on / off
  • `/F1Debug panel (the legend shows ~)
  • Any keyLeave the title screen (also a click or any gamepad button; not Shift, Ctrl, Alt, Tab, F5, F11, F12…)
  • LTitle screen: the language row (← / → choose EN · 日本語 · 中文, Enter switches and reloads, Esc back; pad LB / RB, A, B)

Gamepad

  • Left stick/D-padMove · D-pad ↑↓ picks answers
  • Right stick/LBRBRotate the camera
  • RTRun
  • ATalk / confirm
  • BCancel · close the map · leave photo mode
  • Y/XZoom in / out
  • BackWorld map (open / close)
  • StartControls legend
  • R-stick clickPhoto mode

Combat (Cinderwatch Pass)

  • J/LMBAttack (again as the blade returns: 3-hit combo) · pad X
  • K/RMBDodge roll (no direction: backstep) · pad B
  • UIO/123Skills Whirl Slash · Ember Bolt · Radiant Nova · pad LT + X / Y / B
  • C/4Healing Draught · pad Y
  • L/MMBLock on / next (hold: release) · pad R-stick click
  • SpaceOpen a chest · rest at a waystone · pad A

On combat levels the pad's X / Y attack and drink instead of zooming (zoom moves to the right stick), the right-stick click locks on and a left-stick click takes photos. These keys do nothing on the other levels.

Good to know

  • Keys are physical positions: on AZERTY, move with Z Q S D.
  • Sound starts after your first key press or click.
  • URL: game.html?level=starfall-vale, ?level=cinderwatch-pass (combat), ?autostart=1 skips the title, ?lang=ja / ?lang=zh plays in Japanese / Chinese. On the title, ← / → pick a level and Enter travels.
  • Console (F12): __game.teleport(x, z), __game.setTime(22), __game.state().

Source of truth: src/engine/core/Input.js (DEFAULT_BINDINGS, DEFAULT_PAD_BINDINGS), src/game/Game.js, src/engine/ui/DialogBox.js, src/game/combat/bindings.js (combat).

The Level Editor

editor.html · Cmd works wherever Ctrl is shown

File

  • AltN/CtrlNNew level (Chrome keeps Ctrl+N)
  • CtrlOOpen
  • CtrlSSave
  • CtrlShiftSSave as
  • CtrlEDownload a .json copy
  • F5Play-test in a new tab
  • Drop a .jsonOpen that file
  • CtrlVWith a whole level's JSON on the clipboard: open it as a new, unsaved level

Tools

  • VSelect / Move
  • BPaint tiles
  • GFill
  • URectangle
  • HHeight
  • TStairs
  • OPlace object
  • PPlayer start
  • IEyedropper
  • XErase objects

Edit

  • CtrlZUndo (one stroke = one step)
  • CtrlY/CtrlShiftZRedo
  • CtrlC/X/VCopy / cut / paste (paste lands at the pointer)
  • CtrlDDuplicate
  • Delete/BackspaceDelete the selection
  • CtrlASelect all objects
  • EscDeselect · cancel the current stroke or drag

Select & place

  • Click/Shift/CtrlSelect / add / toggle
  • Drag empty groundBox select
  • Drag+AltMove · Alt = no snapping (also when placing)
  • R/ShiftRRotate ±15° (selection or Place ghost)
  • CtrlR/CtrlShiftRRotate ±90°
  • ←↑↓→Nudge 0.5 · Shift 2 · Alt 0.1
  • Double-clickFocus · inside an area: select it
  • Click, clickordragPlace a fence or bridge · drag a region

Terrain

  • [/]Brush size 1–9
  • Alt+clickPick the tile and level under the pointer (Height tool: the level)
  • Shift+clickPaint: straight line from the last stroke
  • Shift+clickFill: replace that tile everywhere
  • ShiftholdRectangle: outline · Height: invert raise / lower
  • Drag across a cliffStairs: a whole flight, foot to top
  • R/ShiftRPlayer start: turn its facing
  • Shift+clickEyedropper: keep picking

View

  • 1/2/3Layout: 3D + 2D / 3D only / 2D only
  • FFrame the selection (nothing selected: the 3D view focuses the pointer)
  • HomeFrame the level
  • CtrlGGrid on / off
  • ?Shortcut list
  • Right-clickContext menu (both views)

2D map

  • WheelZoom to the cursor
  • Right-drag/Middle-dragPan
  • Space+dragPan
  • Double-clickFocus an object (Select tool)
  • Right-clickContext menu (a click without dragging)

3D view

  • Right-dragOrbit
  • Middle-drag/Shift+right-dragPan
  • Space+dragPan
  • WheelZoom toward the cursor
  • F/double-clickFocus (double-click: Select tool; on open ground it looks at that point)
  • hold right+WASDFly (Shift: faster)
  • hold right+Q/ETurn while flying
  • Q/ERotate the gameplay camera

Fields & dialogs

  • EnterCommit a field · confirm a dialog
  • EscRestore a field · close a dialog or menu
  • CtrlEnterCommit a multi-line text
  • Tab·ShiftTabIn a script: indent / outdent at a line's start or on selected lines (elsewhere: next / previous field)
  • WheelStep a focused number box
  • CtrlS·CtrlShiftS·F5Work even while typing (the field commits first)

Tool and view keys never fire while a text field has focus.

Source of truth: src/editor/EditorApp.js (_buildCommands, _shortcutGroups, _onKeyDown), src/editor/tools/*.js (keyDown, modifiers), src/editor/map2d/Map2DView.js, src/editor/viewport3d/Viewport3D.js.
